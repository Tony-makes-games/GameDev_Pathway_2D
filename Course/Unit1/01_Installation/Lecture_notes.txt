Godot Installation – Lecture
1. Introduction

Godot is a free and open-source game engine used to create 2D and 3D games.

In this lecture, students will learn how to:

Download Godot
Install Godot
Understand the Godot launcher/editor
Create a project
Configure the project
Run the first scene
Understand the basic Godot project structure
2. What is Godot?

Godot is a cross-platform game engine.

It supports:

2D game development
3D game development
UI development
Animation
Physics
Audio
Networking
Shaders and VFX
Scripting
Supported Platforms

Godot can be used to develop games for:

Windows
Linux
macOS
Android
iOS
Web
3. Godot System Requirements

For beginner game-development work, a modern computer with the following is recommended:

Component	Recommended
OS	Windows 10/11 64-bit
RAM	8 GB or more
CPU	Modern dual/quad-core processor
GPU	Integrated GPU for basic projects; dedicated GPU for advanced 3D
Storage	Several GB of free space
IDE	Godot Editor

For classroom teaching, Godot 4.x should be used consistently across all student machines.

4. Downloading Godot

Go to the official Godot website:

Godot Engine

Choose the appropriate version for the operating system.

For Windows, students will generally see options such as:

Standard
.NET
Standard Version

Uses GDScript and is suitable for beginners.

.NET Version

Adds support for C# scripting.

Recommendation for this course

For a beginner Godot course:

Use the Standard version with GDScript.

5. Installing Godot on Windows

Godot's Windows distribution can be used without a traditional installer.

Steps

Step 1: Download the Windows version.

Step 2: Extract the downloaded ZIP file.

For example:

C:\Godot\

Inside the folder you will find the Godot executable.

Example:

Godot_v4.x-stable_win64.exe

Step 3: Double-click the executable.

Godot Editor will open.

6. Creating a Desktop Shortcut

For convenient classroom use:

Right-click the Godot executable.
Select Show more options if required.
Choose Send to → Desktop (create shortcut).

Students can then launch Godot directly from the desktop.

7. Godot Project Manager

A good project organization is important.

Example:

GodotProjects/
└── MyFirstGame/
    ├── project.godot
    ├── scenes/
    ├── scripts/
    ├── assets/
    ├── textures/
    ├── audio/

Godot automatically creates the important project configuration file:

project.godot

Classroom Recommendation

For basic 2D projects:

For advanced desktop 3D projects:

15. Understanding .tscn

Godot scenes commonly use:

.tscn

For example:

main.tscn
player.tscn
enemy.tscn
level1.tscn

A scene stores:

Nodes
Node properties
Node hierarchy
Attached scripts
Resources
16. Run the Project

Press:

F6

to run the current scene.

Press:

F5

to run the project.

Difference
Key	Purpose
F6	Run current scene
F5	Run project
17. Main Scene

When pressing F5 for the first time, Godot may ask:

Select the main scene.

Select:

main.tscn

This tells Godot:

"Start the game from this scene."

18. Project Settings

Open:

Project → Project Settings

Project Settings contains configuration for the game.

Important categories include:

Application
Project name
Main scene
Project icon
Display
Window size
Stretch settings
Window behavior
Input Map

Used to create controls such as:

move_left
move_right
jump
attack
interact
Rendering

Controls graphics-related settings.

Physics

Controls physics-related settings.

19. Setting the Window Size

For example, a 2D game can use:

Width: 1280
Height: 720

This gives a:

16:9

aspect ratio.

Other common resolutions include:

1920 × 1080
1280 × 720

For beginner projects, 1280 × 720 is a convenient working resolution.

23. Common Installation Problems
Problem 1: Godot does not start

Possible causes:

Unsupported operating system
Graphics driver problem
Incorrect executable
Corrupted download

Try downloading Godot again from the official site.

Problem 2: Project does not run

Check:

Project → Project Settings

and verify that a main scene is configured.

Problem 3: Scene does not appear

Make sure the scene has been saved:

Ctrl + S

and verify that the .tscn file exists in the FileSystem dock.

Problem 4: Students have different Godot versions

This can cause differences in:

Editor interface
Node properties
Rendering
APIs
Project behavior
Classroom rule

All students should preferably use the same Godot 4.x version for the entire course.

26. Key Concepts

Students should remember:

Godot
   ↓
Project Manager
   ↓
Create Project
   ↓
Godot Editor
   ↓
Scene
   ↓
Nodes
   ↓
Scripts
   ↓
Run Project
Most important terms

Godot → Game engine

Project → Complete game/application

Scene → Reusable collection of nodes

Node → Building block of a Godot game

Script → Program logic

Resource → Data used by nodes/scenes

Project Manager → Creates and manages projects

Editor → Environment used to develop the game
